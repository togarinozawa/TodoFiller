# スキマスの入れ方

カレンダーの空いている時間に、勉強や用事を自動で割り振るAndroidアプリです。
Android 8.0 以上で動きます（iPhone では使えません）。

## 1. ダウンロード

スマホのブラウザで次のリンクを開きます。

https://raw.githubusercontent.com/togarinozawa/TodoFiller/dist/skimas.apk

## 2. インストール

Playストアを通さないアプリなので、途中で何度か確認が出ます。どれも進んで大丈夫です。

1. ダウンロードが終わったら「開く」
2. 「この提供元のアプリは許可されていません」と出たら「設定」→「この提供元のアプリを許可」をオン → 戻る
3. 「インストール」
4. 「Playプロテクトによりブロックされました」「安全でない可能性があります」と出たら
   「詳細」→「インストールする（安全でない可能性あり）」
   （Playストア以外から入れるアプリには、必ずこの警告が出ます）
5. 「アプリをスキャンしますか？」と聞かれたら、どちらを選んでも入れられます

## 3. はじめに

最初に使い方の説明が出て、そのあと「はじめる前の準備」の画面になります。
上から順にボタンを押して、全部に「済」が付けば準備完了です。

**いちばん大事なこと:** Googleカレンダーの予定のタイトルの**末尾**に「家」か「外」を付けた時間にだけ、
スキマスが予定を入れます（例:「自習 家」「電車 外」）。これが無いと何も入りません。

## 4. 困った時・欲しい機能がある時

どの画面でも、いちばん上に **「不具合・要望を作者に送る」** の帯があります。
押して種類（不具合／欲しい機能／変えてほしい所）を選び、一言書いて「送る」→ LINE を選んで作者に送ってください。
どの画面から送ったかと、アプリの版は自動で付きます。

アプリが止まった後に開くと、帯が赤くなります。その時に送ってもらえると直しやすいです。

## 5. 更新

新しい版が出ると、アプリを開いた時に「アップデート」と出ます。「更新」を押すだけです。
初回だけ「このアプリからのインストールを許可」を求められるので、オンにしてください。

## 6. データについて

- 予定もタスクも、全部スマホの中だけにあります。作者を含め、誰にも見えません
- アプリの通信は、新しい版が出ていないかの確認だけです
- 作者に届くのは、自分で「作者に送る」から送った文章（と、そこに自動で付く画面名・版・機種）だけです
- アンインストールや機種変更でデータは消えます。設定 →「バックアップを書き出す」で控えを取っておけます
